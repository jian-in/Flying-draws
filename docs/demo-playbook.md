# Flying draws 演示录制分镜手册（Demo Playbook）

本手册提供两支 **15 秒高冲击力首屏 GIF / 短视频** 的分镜级实操步骤，用于展示 Flying draws 最核心、最不可替代的两大能力：

1. **GIF 1（照图活化 + 提议手改回流）**：白板架构照片 / 截图 → `trace_image` 一键还原保留原配色的可编辑草稿 → 用户在虚线提议上直接改字、拖拽、局部删框后点击「对，就这样」，手改差异自动编译回流给 Agent。
2. **GIF 2（像素级圈改 + 多轮视觉演进墙）**：前端页面截图红圈批注（自动逆映射原图像素坐标）→ Agent 改代码重渲染 → 画布自动长出带改动文件摘要连线的 `v1 → v2 → v3` 演进链。

---

## 录制前统一准备（窗口与画质规范）

- **分辨率与帧率**：推荐录制区域 `1440×900`（逻辑像素），帧率 `24 fps`（成片体积控制在 `4–6 MB` 以内，GitHub README 秒开）。
- **并排吸附构图（顺带展示 Win32 伴随吸附）**：
  - 左侧放编码终端（Claude Code / Codex）或浏览器预览（占宽约 `42%`）；
  - 右侧打开 Flying draws，向左侧窗口边缘拖近松手（`<= 32px` 自动物理像素贴合），保持纸色浅底 `#fffbe6`，视觉干净高对比。
- **零门槛环境自检**：
  ```bash
  npm run build
  node out/bridge/index.js doctor
  ```
- **示例画板热身（可选）**：
  可将 `examples/architecture-sketch.excalidraw` 复制进 `~/.flyingdraws/boards/demo.excalidraw`（或用 `node scripts/inspect.mjs examples/architecture-sketch.excalidraw` 预览结构），新建空白画板录制下方两段分镜。

## GIF 1：白板架构截图 → `trace_image` 活化 → 手改提议 Diff 回流（15s）

### 核心看点
路人第一眼看懂：**静态死图进去，保留配色的活矢量出来；不用打字解释哪里画错了，直接在半透明虚线提议上动手改，Agent 秒懂你的手改意图。**

### 逐秒分镜表

| 时间轴 | 画面动作（用户实操） | 界面/底层响应（镜头重点） |
|---|---|---|
| **00s – 03s** | 往空白画板 `Ctrl+V` 粘贴一张白板手绘架构照片或架构截图（`I1`）。选中图片：内置面板直接点 **「转成可编辑图 ↗」**（或外部 Claude Code 输入：`把画布里的图 I1 用 trace_image 提议还原成可编辑架构图，并删掉旧备注`）。 | 画布右侧（`place: "beside"`）瞬间浮现一套与原图等大、保留原边框/填充十六进制色值的 **55% 半透明虚线提议层**；若附带删除/修改旧元素，目标外围出现 `#e03131` 红色虚线预览框（上方写着 `删除`）。顶部弹出横幅：`agent 画了它的理解（虚线半透明部分），可以直接在上面改：`。 |
| **03s – 09s** | **不敲聊天框，直接在画布虚线提议上动手改 3 件事**：<br>1. 双击其中一个虚线方框，把 `Auth Service` 改成 `OAuth2 网关`；<br>2. 把 `Redis` 虚线框往右下拖开一截（绑定的虚线箭头自动跟着走）；<br>3. 点选那处不想要的红色 `删除` 虚线标记框，按 `Delete` 单独否决该处删除。 | Excalidraw 丝滑响应拖拽与改字；单处红色预览框消失，被保护的原元素安然无恙。 |
| **09s – 12s** | 鼠标点击顶部横幅主按钮 **「对，就这样」**。 | 所有保留的半透明虚线瞬间转为 **100% 实线正式画布元素**，剩余预览标记框自动清场。 |
| **12s – 15s** | 视线切向左侧 Agent 终端 / 面板输出（停留 2.5 秒定格）。 | `canvas_wait` 原样收到编译好的中文自然语言 Diff：<br>`- 不同意删除文字「限流备注」`<br>`- 把节点「Auth Service」的文字改成了「OAuth2 网关」`<br>`- 把节点「Redis」往右下挪了` |

> **剪辑提速技巧**：模型视觉推理等待段（约 3–5 秒）在后期剪成 `0.4s` 快进并保留光标连贯，把完整的 12 秒留给「原图 → 虚线浮现 → 手改三连 → 实线转正 + Diff 回显」。

## GIF 2：页面截图红圈批注 → `v1 → v2 → v3` 视觉演进墙自动上墙（15s）

### 核心看点
路人第一眼看懂：**对比一次性 DOM 点选改完即忘，Flying draws 把每一版页面截图、原图像素级红圈批注、以及改了哪几个源码文件的演进连线全部钉在同一面墙上。**

### 前置准备
1. 本地启动一个待调整的前端项目（例如运行在 `http://localhost:5173` 的登录或仪表盘页）。
2. 打开 Flying draws 右侧 **「内置 Agent」** 面板，工作目录指向该前端仓库，确认勾选 **「自动把页面结果图连入画布演进链」**（默认开启），取消勾选「先拟计划」以便直接连贯录屏。
3. 画布左侧先放入第 1 版页面截图（`v1`，即使缩放到画布上只有一半大小、甚至裁剪过也完全支持）。

### 逐秒分镜表

| 时间轴 | 画面动作（用户实操） | 界面/底层响应（镜头重点） |
|---|---|---|
| **00s – 04s** | 切手绘笔（快捷键 `P`，选红色 `#e03131`），直接在 `v1` 页面截图的顶栏按钮区域画一个红圈，旁边敲一行字 `主按钮改成暖黄黑框，间距拉大`；框选这片区域，在右侧面板输入 `按红圈批注修改页面并重新渲染确认`，按 `Ctrl+Enter` 发送。 | 面板显示 `发送范围：已选 3 项（自动带上重叠底图）`。底层 `canvasRectToImagePixels` 自动把缩放后的画布红圈逆映射成原图真实像素区域（如 `pixelBbox: 820, 48, 260, 84`）连同底图发给 Fuxi。 |
| **04s – 09s** | Agent 修改源码并调用 `render_page` 重新截取真实页面（工具审批卡点一次「本次允许」）。 | **高光时刻 1**：无需人工拖拽截图！新版渲染图 `v2` 自动落位在 `v1` 右侧 `160px` 空位，顶部带 `v2 · 1280×720` 题注，一条蓝色演进箭头自动从 `v1` 连向 `v2`，箭头上清晰标着 **`第 2 轮 · App.tsx, styles.css`**！ |
| **09s – 12s** | 顺手在新长出来的 `v2` 结果图底部卡片上再画一笔红圈，输入 `把底部状态栏改成胶囊圆角` 发送第 3 轮。 | **高光时刻 2**：`v3` 再次自动接在 `v2` 右侧，长出 `v2 → v3`（标着 `第 3 轮 · styles.css`），画布拉远全景呈现完整的 **`v1 批注原图 → v2 结果图 → v3 结果图`** 横向视觉演进墙。 |
| **12s – 15s** | 点击画布底部筛选栏切换 **「我画的」** ↔ **「全部」**（或 `@Fuxi` 席位色点）。 | 切「我画的」时，Agent 插入的结果图、演进箭头与题注瞬间隐去，只留最初的草图与手绘；切回「全部」演进墙完整重现，收尾定格。 |

## 导出高质量轻量 GIF 命令参考（FFmpeg 两步调色板法）

录制成 `.mp4` 后，使用全局调色板防抖动导出清晰锐利的线稿风 GIF：

```bash
ffmpeg -i raw-demo.mp4 -vf "fps=24,scale=1280:-1:flags=lanczos,palettegen=stats_mode=diff" palette.png
ffmpeg -i raw-demo.mp4 -i palette.png -lavfi "fps=24,scale=1280:-1:flags=lanczos [x]; [x][1:v] paletteuse=dither=bayer:bayer_scale=5:diff_mode=rectangle" -y demo.gif
```
